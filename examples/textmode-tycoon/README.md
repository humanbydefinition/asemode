# Textmode Tycoon

This folder contains Asemode's conversion of the collaborative **Textmode
Tycoon** canvas from `draw.textmode.art` *(no longer available)*. The event ran
from May 8 to May 15, 2026. Its prompt invited participants to build a shared
textmode theme park.

## Files

- `textmode-tycoon.aseprite` is the native Aseprite project.
- `textmode-tycoon.textmode.json` is the portable Textmode document.
- `textmode-tycoon.png` is a rendered preview.

The project converts the event canvas into Asemode's native layer format.
The contributors below are credited from the event's drawing
records.

The artwork uses [CHUNKY](https://batfeula.itch.io/chunky), a font by Batfeula
included in official Asemode release builds. If you built Asemode from
source without the optional fonts, download CHUNKY from its creator and add the
TTF to your Asemode Library.

# Security Policy

## Supported Versions

Security fixes are provided for the latest release on `main`.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases, prereleases, and local modifications | No |

## Reporting a Vulnerability

Report suspected vulnerabilities privately to
[hello@textmode.art](mailto:hello@textmode.art). Do not open a public issue or
pull request for a security report.

Include the Asemode version, Aseprite version, operating system, steps to
reproduce the issue, and its expected impact. The maintainers will make a best
effort to acknowledge and investigate the report, keep you informed, and
prepare a fix when they confirm an issue.
